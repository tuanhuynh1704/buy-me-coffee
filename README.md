# ☕ Buy Me A Coffee - VietQR Donation

Trang web nhận donate & ủng hộ một ly cà phê qua mã QR ngân hàng chuẩn Napas247 (TPBank) độc lập, gọn nhẹ và hiện đại.

---

## 🚀 Tính năng nổi bật

- ☕ **Chọn ly cà phê nhanh**: 1 ly (25k), 2 ly (50k), 3 ly (75k), Bữa sáng (100k) hoặc tùy chọn.
- 📱 **Mã QR TPBank chuẩn Napas247**: Quét mã chuyển khoản trực tiếp qua mọi App ngân hàng Việt Nam.
- 💌 **Gửi lời nhắn & Thông báo về Email**: Tự động gửi email thông báo khi có người ủng hộ.
- 📋 **Sao chép 1 chạm**: Sao chép STK, nội dung CK nhanh chóng kèm hiệu ứng pháo hoa Confetti.
- 🌙 **Hỗ trợ Dark / Light Mode**: Giao diện kính mờ Glassmorphism mượt mà trên cả điện thoại và máy tính.
- 🌐 **Chạy online miễn phí 100% trên GitHub Pages**.

---

## 🛠️ Hướng dẫn đưa lên GitHub Pages (Chạy Online Miễn Phí)

1. **Tạo Repository mới trên GitHub**:
   - Truy cập [github.com/new](https://github.com/new) và tạo một repo mới (ví dụ: `buy-me-a-coffee`).

2. **Đẩy mã nguồn lên GitHub**:
   Mở terminal tại thư mục dự án và chạy các lệnh:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Buy me a coffee web app"
   git branch -M main
   git remote add origin https://github.com/<tai-khoan-cua-ban>/buy-me-a-coffee.git
   git push -u origin main
   ```

3. **Bật GitHub Pages**:
   - Vào Repository trên GitHub -> chọn tab **Settings**.
   - Tìm mục **Pages** ở cột bên trái.
   - Tại phần **Branch**, chọn `main` và bấm **Save**.
   - Đợi khoảng 1 phút, bạn sẽ nhận được đường link online dạng:
     `https://<tai-khoan-cua-ban>.github.io/buy-me-a-coffee/`
